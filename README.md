# kingnathanal.github.io

This GitHub Pages site redirects visitors to [Will Britton's portfolio](https://www.williambritton.dev).

The active portfolio lives in [kingnathanal/williambritton](https://github.com/kingnathanal/williambritton) and deploys through Azure Static Web Apps.

## Why this repository exists

`kingnathanal.github.io` is the public GitHub Pages address associated with the `kingnathanal` account. It remains online as a lightweight handoff for older links and visitors who reach it through GitHub.

The former Jekyll blog and theme are intentionally removed from the published source. Their history remains available in Git.
